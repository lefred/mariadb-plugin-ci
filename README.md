# mariadb-plugin-ci

## MariaDB PLugin CI

Reusable GitHub Actions workflows for building and packaging my MariaDB Server plugins

## Supported MariaDB versions

- MariaDB 11.8
- MariaDB 12.3

## Reusable workflow

The reusable workflow is:

```text
lefred/mariadb-plugin-ci/.github/workflows/build-plugin.yml
```
